DSF 高通量分析综合平台 - 简明使用说明

🌟 核心理念与全局配置本系统专为基于片段的药物发现 (FBDD) 及高通量小分子筛选设计。

平台内置了亚网格二次插值法（打破仪器采样步长限制，精确计算小数点级 Tm）以及基于稳健统计学的自适应智能质控 (Auto QC)。Auto QC (强烈建议开启)：系统会自动提取整块 96 孔板的中位数数据，为你单独定制该板的“高自发荧光”与“淬灭曲线”判断阈值，完美抵抗批次效应。

🖱️ 交互图谱使用技巧 (全模块通用)当你在界面上看到 96 孔板网格时，你可以：单选/框选：按住鼠标左键直接拖拽出一个长方形以批量选定孔位。多选/追加选定：按住键盘的 Shift 键，继续点击或拖拽其他区域，实现跨区不连续选孔。取消选定：在网格外部边缘的空白区域双击鼠标，即可瞬间清除所有选框。图片导出：鼠标悬浮在任意生成的图表（如散点图、柱状图）右上角，点击照相机图标 📸 即可保存高清图表。

🎯 模块 A：初筛 (单板模式)适用场景：对单一化合物库的标准 96 孔板数据进行快速解析。操作流：上传仪器导出的 .xls/.xlsx 原文件。系统默认 G12 为阴性对照(基线)，H12 为阳性对照。若实验操作有变，可在下方网格圈选真实对照孔，点击【设为 NC】或【设为 PC】进行动态覆盖。若发现气泡等导致的异常曲线，圈选后点击【一键剔除】。点击【执行计算】，系统将生成排除了异常数据的 Delta Tm 散点图及复核报告。

🧪 模块 B：再验证 (自定义排板)适用场景：验证苗头化合物 (Hit)，评估不同组别、不同摩尔浓度梯度下的剂量-效应关系 (Dose-Response)。操作流：上传包含多板验证数据的多个文件。使用下拉菜单切换板位，在 96 孔板上圈选特定区域。在下方输入框填入“化合物名称”和“浓度比”（如 1:50），点击【设为实验组】。如果选错，可直接在下方生成的表格内双击修改或删除。点击【执行计算】，系统会过滤掉对照组的干扰，为每个化合物独立绘制标准的带有误差棒(SD)的柱状图与趋势折线图。

🌌 模块 C：高通量多板初筛 (批量整合与补漏)适用场景：一次性处理十几个筛选板，并将实验中“漏掉的化合物”统一排到一张杂乱的“补漏板”上。操作流：批量选中并上传所有筛选文件。对大部分规则的板，设定为“标准规则板”。对于拼凑出来的杂板，设定为“自定义补漏板”。利用 96 孔画板圈选孔位，手动为其输入对应的 Compound ID 建立映射。点击【执行计算】，系统会智能为每张板独立计算基线，最后将成百上千个有效分子的 Delta Tm 汇聚成一张宏大的全局散点分布图，助你纵览整个化合物库的活性全貌
